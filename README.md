# FLONOS RECODE

**FLONOS RECODE** — это бесплатный чит для Minecraft в формате **.jar**, предназначенный для PvP и HvH (Hack vs Hack) сражений.

## 🖼️ Визуал

![FLONOS GUI](https://i.postimg.cc/sg4yBfbQ/Screenshot-2026-10-28-202540.png)

## ⚙️ Системные требования

- **Операционная система:** Windows 10/11
- **Версия Minecraft:** Java Edition 1.21.11
- **Среда:** Java 8

## 📦 Запуск

1. Поместите `FLONOS.jar` в папку с модами вашего Minecraft (версия 1.21.11).
2. Запустите игру через fabric.
3. В главном меню или в мире нажмите **RSHIFT** для открытия GUI.
4. Настройте модули и наслаждайтесь игрой.
